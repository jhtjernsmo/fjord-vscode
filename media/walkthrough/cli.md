# The fjord CLI

Fjord for VS Code uses the same `fjord` command-line tool as the app's terminal users and AI agents. Your data stays in Fjord's local database; nothing goes to a server.

It's found automatically in these places:

- on your `PATH`
- Homebrew (`brew install jhtjernsmo/fjord/fjord-cli`)
- `~/.cargo/bin`, `~/.local/bin`, `~/bin`

If it isn't there, **Install the CLI** downloads it from the latest Fjord release into the extension's own folder.
